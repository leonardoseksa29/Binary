Какво всъщност е Git

Git е разпределена система за контрол на версиите, която ти позволява да проследяваш промените в кода, 
да работиш в екип и да управляваш различни версии на проектите си. Вместо да записва разлики между файлове, 
Git работи със snapshot-и — снимки на цялото състояние на проекта. 
Това го прави бърз, надежден и много ефективен.
